# Referências do Figma

Extraídas do arquivo do desafio (cópia em rascunho do candidato, para permitir leitura via API).

- `desktop-*.png` / `mobile-*.png` — render de cada frame (referência visual e base da regressão visual).
- `figma-structure.xml` — árvore de nós (ids, nomes, posições e tamanhos) de todos os frames.
- Assets usados pela aplicação:
  - `public/images/nfts/*.webp` — as 4 artes originais (PNG 1254×1254, ~2 MB cada) convertidas para WebP
    em 256/512/1024 px (6–73 KB). Duas imagens do arquivo não aparecem em nenhum frame e foram descartadas.
  - `src/assets/icons/*.svg` — ícones (Iconly), logo e redes sociais exportados como SVG.
